# One Line, One Laugh

Entry for the [One Line, One Laugh](https://make.fun/c/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) bounty on make.fun — exactly one funny line, no setup notes, judged head-to-head by an AI comedy judge.

## The line

> My Roomba mapped my apartment and emailed the floor plan to my landlord with the subject line: 'He lives like this.'

## How it works

`main.py` writes that single line to `/output/entry.txt` (116 characters, one line, well inside the 1–200 character gate), then reads it back and verifies the gate holds before exiting. It never deletes the output directory.

Run it locally:

```sh
OUTPUT_DIR=/tmp/laugh-out python3 main.py
```

## Why this line

A familiar gadget with an absurd escalation: the vacuum doesn't just clean, it maps the flat and rats out its owner to the landlord. The punchline lands inside the line, in the subject line, with no setup the reader has to supply — and it's easy to repeat to someone else.
